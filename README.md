# Paradise Nursery

Paradise Nursery is a responsive online houseplant shopping application built with React, Vite, Redux Toolkit, and React Router.

## Features
- Welcome landing page with a Get Started button
- Company information page
- Plant catalogue with three categories and six unique plants in each category
- Add-to-cart controls and a dynamically updated cart count
- Shopping cart with quantity controls, item removal, line totals, and grand total
- Continue Shopping and Coming Soon checkout actions

## Technology
- React
- Vite
- Redux Toolkit and React Redux
- React Router
- CSS

## Run locally
1. Install Node.js.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed by Vite.

## Project structure
- `src/App.jsx` – application routes and shared navigation
- `src/App.css` – application styles and landing-page background image
- `src/components/AboutUs.jsx` – company information
- `src/components/ProductList.jsx` – catalogue and navigation bar
- `src/components/CartItem.jsx` – shopping cart page
- `src/redux/CartSlice.jsx` – Redux cart state and reducers
